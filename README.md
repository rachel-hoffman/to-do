# To-Do Desktop Application
## 8.17.26

## How to Use
Download the .exe file from the code files of this repository to get started. Be sure to save the application to a permanent location.
<br>
Once you save your changes, a file containing your saved data will save to the same location at the .exe app. Please be aware that this data file is unencrypted CSV format.

<ul>
    <li>Python</>
    <li>PySide 6</>
    <li>CSV data storage</>
